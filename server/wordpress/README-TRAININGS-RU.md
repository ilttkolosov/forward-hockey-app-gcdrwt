# Расписание тренировок: WordPress

Файл `forward-training-schedule.php` одновременно решает две задачи:

1. добавляет защищённую страницу **Инструменты → Импорт тренировок**;
2. публикует read-only API `GET /wp-json/app/v1/get-trainings` для мобильного приложения.

## Установка

1. Создайте каталог `wp-content/mu-plugins`, если его ещё нет.
2. Скопируйте туда `forward-training-schedule.php`.
3. Убедитесь, что активен плагин **The Events Calendar**.
4. Откройте в WordPress **Инструменты → Импорт тренировок**.

MU-плагин загружается автоматически и не зависит от активной темы. Отдельное правило `.htaccess` не требуется.

## Импорт

Поддерживаются JSON и XML. Рекомендуемый рабочий формат — JSON; готовый файл для расписания с изображения находится в `training-schedule-2026-08.json`.

- `year` необязателен. Без него берётся текущий год WordPress.
- `weekday` обязателен: импортер сверяет его с календарной датой.
- `type`: `ice`/`лед` либо `ofp`/`ОФП`/`земля`.
- `uid` необязателен. По умолчанию он стабильно формируется из команды, типа и времени начала.
- повторный импорт того же занятия обновляет событие вместо создания дубля;
- `replace_range: true` переносит в корзину ранее импортированные занятия этой команды, которых нет в новом файле внутри `range_from`—`range_to`;
- перед импортом всегда рекомендуется кнопка **Проверить без записи**.

Для расписания 3–9 августа 2026 года поле `year` намеренно не указано: в текущем 2026 году даты корректно соответствуют понедельнику–воскресенью. Если этот же файл запустить в другом году, проверка дня недели остановит импорт — тогда следует явно указать нужный `year`.

## Проверка API

```powershell
$url = 'https://www.hc-forward.com/wp-json/app/v1/get-trainings?date_from=2026-08-01&date_to=2026-08-31&team=forward-2014'
Invoke-RestMethod -Uri $url | ConvertTo-Json -Depth 8
```

Пустое расписание возвращает HTTP 200, `data: []` и `count: 0`. Это штатный результат, а не ошибка подключения.
