# Встроенные логотипы команд

Файлы `team_<ID>.<расширение>` входят в установочный пакет приложения и доступны
сразу после чистой установки без сетевой загрузки и без изменения версии
справочника команд.

- `npm run logos:sync` — получить актуальный список команд из API, скачать все
  доступные изображения и обновить манифест/TypeScript-реестр.
- `npm run logos:generate` — только пересобрать локальный TypeScript-реестр без
  обращения к сети. Эта команда также выполняется при `postinstall` и проверке.

`generated.ts` редактировать вручную не нужно. Для новой или изменившейся
картинки потребуется новая сборка приложения, поскольку изображение является
частью установочного пакета.
