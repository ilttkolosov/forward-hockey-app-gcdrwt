# Smoke-тесты стабилизационной ветки

Тесты выполняются на Android и iOS после `npm ci`, `npm run check` и preview-сборки.

## 1. Первый запуск с интернетом

- Удалить приложение и установить заново.
- Запустить при стабильной сети.
- Убедиться, что загрузились команды, игроки, турниры и матчи.
- Закрыть приложение штатно.

Ожидание: запуск завершается, офлайн-баннер отсутствует, данные сохранены.

## 2. Первый запуск без интернета

- Установить приложение на чистое устройство.
- Отключить Wi-Fi и мобильные данные.
- Запустить приложение.

Ожидание: приложение не зависает; показано сообщение, что для первого запуска требуется интернет, и кнопка «Повторить».

## 3. Повторный запуск без интернета

- Сначала успешно выполнить сценарий 1.
- Полностью закрыть приложение.
- Отключить сеть и открыть приложение снова.

Ожидание: приложение открывается с последним успешным набором; сверху виден офлайн-баннер.

## 4. Потеря сети во время работы

- Открыть приложение онлайн.
- Отключить сеть и обновить главный экран жестом pull-to-refresh.

Ожидание: текущие данные не исчезают и не превращаются в пустые списки; появляется баннер.

## 5. Восстановление сети

- После сценария 4 включить сеть.
- Выполнить pull-to-refresh.

Ожидание: данные обновляются; после успешного ответа предупреждение исчезает.

## 6. Главный экран и ближайшие матчи

- Проверить текущие матчи, ближайшие игры, количество игроков и турниров.
- Сравнить данные с API/сайтом.

Ожидание: корректные даты, команды, счёт и количество элементов; настоящий пустой ответ показывается как отсутствие матчей.

## 7. Карточка матча и видео

- Открыть матч онлайн, затем повторно открыть его офлайн.
- Проверить счёт, периоды, команды и арену.

Ожидание: данные ранее открытого матча доступны офлайн; видео без сети может быть недоступно и не должно ломать карточку.

## 8. Архив, сезоны и турниры

- Открыть архив, сезон, список турниров и таблицу турнира онлайн.
- Повторить после перезапуска без сети.

Ожидание: ранее загруженные списки и таблицы доступны из кэша.

## 9. Игроки и Memory

- Открыть список игроков и несколько карточек.
- Запустить Memory и завершить уровень.
- Повторить без сети.

Ожидание: локальные игроки, фотографии и Memory работают; рекорды сохраняются.

## 10. Push-уведомления

- Проверить включение и отключение push при наличии сети.
- Запустить приложение офлайн с ранее выбранной настройкой.

Ожидание: сетевой сбой проверки подписки не блокирует запуск и не удаляет локальные данные.
