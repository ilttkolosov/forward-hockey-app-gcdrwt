# История изменений

Формат основан на Keep a Changelog. До введения отдельных релизных тегов изменения группируются по этапам стабилизации.

## [Unreleased] — P0 offline-first

### Добавлено

- Постоянный типизированный кэш стартовой конфигурации.
- Миграция ранее сохранённых версий, турниров и справочников в новый startup cache.
- Постоянный кэш списков матчей по параметрам запроса.
- Постоянный кэш открытых карточек матчей.
- Стратегия stale-while-revalidate для повторного запуска.
- Отслеживание состояния сети через NetInfo.
- Глобальный баннер об отсутствии сети или использовании сохранённых данных.
- Понятная ошибка для первого запуска без сохранённых данных.
- Русская проектная документация и перечень smoke-тестов.

### Изменено

- Сетевые ошибки `getGames()` больше не возвращаются как успешный пустой список.
- Обновление игроков не сбрасывает рабочие флаги до успешного завершения.
- При ошибке обновления команд, справочников или игроков приложение продолжает работу с последним успешным набором.
- Проверка и восстановление фотографий игроков не запускается офлайн.
- Повторная попытка запуска корректно очищает старую ошибку и возвращает экран прогресса.

## [1.0.58-stabilization] — 2026-08-07

### Исправлено

- 116 ошибок TypeScript и ошибки typed routes Expo Router.
- Битый импорт мини-игры Memory.
- Все предупреждения React Hooks.
- Android Bundle JavaScript build.
- Некорректные восьмизначные цвета Expo Config.
- iOS target с именем `14`; техническое имя заменено на `ForwardHockey14` с сохранением отображаемого имени `ХК Форвард 14`.
- Конфигурация Firebase для EAS через файловую переменную окружения.

### Инфраструктура

- Добавлен и зафиксирован `package-lock.json`.
- Настроены `typecheck`, `lint`, `check` и генерация route types.
- EAS CLI закреплён на 21.7.0 без локальной зависимости.
- `expo-doctor` доведён до 18/18.
- Создана ветка `stabilization/foundation`.
- Успешно проверены Android APK и iOS Ad Hoc IPA.
